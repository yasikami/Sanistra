# Sanistra

Sanistra — музыкальный плеер для Windows 11.

## Возможности

- Воспроизведение аудиофайлов и управление очередью.
- Темы, настраиваемый акцент, масштаб и фоновое изображение.
- Избранное, плейлисты и сохранение пользовательских настроек.
- Проверка обновлений через GitHub Releases.

## Запуск из исходников

1. Установи Python 3 для Windows.
2. Запусти `scripts/run_player.bat`.

## Сборка Windows EXE

1. Запусти `scripts/build_exe.bat`.
2. Готовый файл появится в `dist/Sanistra.exe`.

## Автообновления

Источник релизов уже указан в `src/player.py`: `yasikami/Sanistra`.

Чтобы обновление было доступно пользователям, собери `dist/Sanistra.exe`, затем создай GitHub Release с тегом вида `v2.2.0` и прикрепи EXE в Assets с точным именем `Sanistra.exe`. Для следующих выпусков повышай номер версии как в `src/player.py` (`APP_VERSION`), так и в теге релиза.

Исходный код и ресурсы находятся в репозитории; готовый EXE следует прикреплять к GitHub Release, а не хранить как обычный исходный файл в корне репозитория.

## Структура проекта

- `src/` — исходный код приложения.
- `assets/` — иконка и изображение зомби.
- `scripts/` — запуск, сборка и локальное применение патчей.
- `config/` — пример конфигурации обновлений.
- `docs/` — история изменений и инструкции.
- `requirements.txt` — Python-зависимости.
