SANISTRA 2.2.0 — КАК ОБНОВИТЬ ПРОЕКТ
===================================

ВАРИАНТ A: ПОЛНЫЙ ПРОЕКТ
1. Скачай Sanistra_2.2.0_organized.zip и распакуй в новую папку.
2. Пользовательская библиотека/избранное/настройки сохраняются отдельно в %APPDATA%\LumenPlayer.
3. Для пересборки EXE запусти scripts\build_exe.bat.

ВАРИАНТ B: ЧАСТИЧНЫЙ ПАТЧ ДЛЯ СУЩЕСТВУЮЩЕГО ИСХОДНОГО ПРОЕКТА
1. Скачай Sanistra_2.2.0_patch.zip и переименуй его в update_patch.zip.
2. Положи update_patch.zip в папку scripts старого проекта.
3. Полностью закрой Sanistra.
4. Запусти scripts\apply_update.bat.
5. После применения запусти scripts\build_exe.bat, если пользуешься Sanistra.exe.

Патч обновляет только перечисленные изменённые файлы; он не содержит библиотеку музыки,
плейлисты, иконку или остальные ресурсы. Не запускай apply_update.bat, пока плеер открыт.

Онлайн-обновления для EXE требуют один раз встроить реальный GitHub owner/repo в src\player.py.
Подробности в ONLINE_UPDATES_RU.txt.
