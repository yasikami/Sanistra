SANISTRA — ОНЛАЙН-ОБНОВЛЕНИЯ
=============================

ИСТОЧНИК УЖЕ НАСТРОЕН

В src/player.py уже указан репозиторий:
UPDATE_REPOSITORY = "yasikami/Sanistra"

Обычному пользователю не нужно вводить репозиторий в настройках. После сборки EXE
приложение автоматически проверяет GitHub Releases при запуске, а в разделе настроек
можно запустить проверку вручную.

ЧТО НУЖНО СДЕЛАТЬ ВЛАДЕЛЬЦУ РЕПОЗИТОРИЯ

1. Собери приложение через scripts\build_exe.bat.
2. Открой https://github.com/yasikami/Sanistra/releases/new
3. Создай release с тегом версии, например v2.2.0 для текущей сборки.
4. Загрузи собранный файл dist\Sanistra.exe в Assets. Имя файла должно быть Sanistra.exe.
5. Опубликуй релиз, не оставляй его в черновиках и не отмечай как prerelease.

Когда выйдет следующая версия, увеличь APP_VERSION в src/player.py, собери новый EXE,
создай новый релиз с более высоким номером версии (например v2.2.1) и добавь Sanistra.exe.
Приложение с уже встроенным источником скачает файл, проверит SHA-256, сохранит резервную
копию старого EXE, заменит его и перезапустится.

ВАЖНО

- Репозиторий должен быть публичным, чтобы загрузка релизов не требовала токена.
- Обычная загрузка исходников/коммит в main не запускает обновление: необходим GitHub Release.
- Сборка, которую пользователь уже установил до добавления встроенного источника, сама
  не узнает о новом адресе. Её надо один раз вручную заменить сборкой с включённым источником.
- Настройки и библиотека сохраняются в %APPDATA%\LumenPlayer для совместимости со старыми версиями.
