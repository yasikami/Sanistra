SANISTRA 2.2.0
- Исправлена синхронизация шкалы позиции с аудиотаймером pygame.mixer.music.get_pos().
- Фактическая длительность после завершения корректирует неточные метаданные.
- Живое применение темы/акцента/масштаба/плотности без перезапуска.
- Добавлен пользовательский фон из PNG/JPG/WEBP/BMP с настройкой затемнения.
- Добавлена кнопка play/pause прямо в строке каждого трека.
- Добавлена тихая проверка обновлений при запуске для релизных сборок, в которые встроен GitHub owner/repo.
